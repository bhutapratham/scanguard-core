\# ScanGuard Core



A lightweight, non-invasive HTTP security header scanner designed to evaluate web endpoints against baseline web security benchmarks.



\## Features

\- Analyzes critical HTTP security headers (HSTS, CSP, X-Frame-Options, X-Content-Type-Options, Referrer-Policy).

\- Generates an objective compliance grade (A to F).

\- Stateless, non-intrusive public header inspection.



\## Setup \& Usage

```bash

pip install -r requirements.txt

python scanner.py
